Bridge connection

Automatic (recommended): one-time setup — python scripts/install_native_host.py --extension-id <id from chrome://extensions>. After that, opening the side panel starts the bridge and fills in the token below by itself; nothing to do here on later sessions.

Manual fallback: run python run.py --serve yourself, then paste the token printed on start (also saved to config/extension_token.txt) below. Always available, whether or not the native host is installed.

Sessions

Soft cap on how many jobs opened from the side panel's job list (step-15h) can be tracked at once. Opening another past this cap is blocked with a message, not silently ignored — close a tracked tab first.
